# Lightspeed Restoration of Greenville: social graphics

Public image hosting for scheduled Facebook, Instagram and Google Business Profile posts.

- `brand/`: logo versions (`wordmark_dark.png` for navy, `wordmark_color.png` for light, `wordmark_white.png` for brand blue) and the IICRC Certified Firm badge.
- `designs/<week>/`: the HTML source of each week's graphics (1080 x 1350). Render with headless Chrome at that window size.
- `graphics/<year>/`: finished JPEGs, named `<post date>-<topic>.jpg`. Posts link to these through raw.githubusercontent.com.

Design rules live in the Playbook tab of the "Lightspeed Social Media" doc.
